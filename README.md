## CodeEraX (Brain 🧠) API

# Intelligence & Logic Layer of the CodeEraX Ecosystem

⸻

# 🚀 Overview

The CodeEraX (Brain 🧠) API is the intelligence and logic layer of the platform.

It builds system logic, orchestrates modular engines, and defines how the application behaves.

All outputs generated by the Brain are sent to the (Heart 💜) API, where they are executed and transformed into a live application.

💥 The (Brain 🧠) API does not execute — it thinks, builds, and instructs.

⸻

# 🏗️ Architecture

User → Frontend → (Brain 🧠) API  → (Heart 💜) API → Frontend


⸻

# 🔁 Internal Flow

User selects engine(s)
        ↓
(Brain 🧠) activates engines
        ↓
(Brain 🧠) builds system logic
        ↓
(Brain 🧠) orchestrates workflow
        ↓
(Brain 🧠) → (Heart 💜) (via bridge)
        ↓
(Heart 💜) executes + stores runtime
        ↓
Frontend displays live application


⸻

# ⚙️ Responsibilities

The (Brain 🧠) API:
	•	Defines system logic
	•	Orchestrates workflows
	•	Activates and manages engines
	•	Combines engine outputs
	•	Prepares structured execution instructions
	•	Sends final logic to (Heart 💜) API

👉 Output:
System Logic (Blueprint for execution)

⸻

# ⚙️ Engine System

Each engine provides a specific capability and operates independently.

Examples:
	•	auth_engine
	•	dashboard_engine
	•	notification_engine
	•	analytics_engine
	•	ai_engine

💥 New features = new engines (no core rewrite needed)

⸻

# 🔗 Heart Integration Layer

The heart/ module handles communication between (Brain 🧠) and (Heart 💜)

Responsibilities:
	•	Send execution requests to (Heart 💜) API
	•	Handle HTTP/client communication
	•	Abstract execution layer from core logic

💥 Keeps (Brain 🧠) clean and modular

⸻

# 📡 API Endpoints

🧠 Build System

POST /brain/build/

Flow:
	1.	Receives build request
	2.	Selects appropriate engine(s)
	3.	Builds system logic
	4.	Dispatches to (Heart 💜)

⸻

# (Heart 💜) API Check

GET /brain/health/

Returns:
	•	(Brain 🧠) API status
	•	Heart 💜 API connection mode
	•	Timeout config
	•	Warnings

⸻

# 🔐 Internal Execution (Protected)
	•	POST /internal/execute/
	•	GET /runtime/<project_id>/

⚠️ Requires HEART_INTERNAL_TOKEN in production

⸻

# 🛠️ Installation

Prerequisites
	•	Python 3.10+
	•	Virtual environment (venv)

⸻

Setup

# Clone repository
git clone <repo-url>

cd codeerax_brain_api

# Create virtual environment
python -m venv venv

# Activate
source venv/bin/activate   # Linux/Mac
venv\Scripts\activate      # Windows

# Install dependencies
pip install -r requirements.txt


⸻

# Environment Setup

cp .env.example .env

Update values accordingly

⸻

# Run Migrations

python manage.py migrate


⸻

# Start Server

python manage.py runserver


⸻

# 🔑 Environment Variables

Key variables:
	•	DJANGO_SECRET_KEY
	•	DJANGO_DEBUG
	•	DJANGO_ALLOWED_HOSTS
	•	DB_ENGINE, DB_NAME, DB_USER, DB_PASSWORD, DB_HOST, DB_PORT
	•	HEART_EXECUTE_URL
	•	HEART_INTERNAL_TOKEN
	•	HEART_REQUEST_TIMEOUT_SECONDS
	•	FRONTEND_URL

💥 If HEART_EXECUTE_URL is empty → local Heart execution is used
